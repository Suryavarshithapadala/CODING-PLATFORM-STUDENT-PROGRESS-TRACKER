# Coding Platforms & Student Progress Tracker

## About the Project
The Coding Platforms & Student Progress Tracker is a C++ application designed to help students manage coding assignments, submissions, and learning progress. It also provides features for faculty and administrators to manage coding problems and monitor student performance.

## Features
- **Admin Module:** Manage application information and users.
- **Faculty Module:** Add coding problems, assign tasks, and monitor progress.
- **Student Module:** Access assignments and track coding activities.
- **Problem Management:** Organize problems by difficulty.
- **Assignment Management:** Manage coding assignments.
- **Submission Tracking:** Store and manage submission details.
- **Progress Tracking:** Maintain student progress records.
- **Report Generation:** Generate student performance reports.
- **File Handling:** Store application data in text files.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- GCC (g++)
- Visual Studio Code

## Project Structure
The project contains C++ source files (`.cpp`), header files (`.h`), text files for data storage, and VS Code configuration files.

## How to Run

### Prerequisites
- Visual Studio Code
- GCC C++ compiler with C++17 support

### Compile
```bash
g++ -std=c++17 CampusCodeTrack.cpp -o CampusCodeTrack.exe
```

### Run on Windows PowerShell
```powershell
.\CampusCodeTrack.exe
```

Note: If the program requires implementations from other `.cpp` files, compile the required files together. Avoid compiling duplicate definitions.
